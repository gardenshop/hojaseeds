# Real product photos go here

The site is already wired to use these files if present — it falls back
to a clean gradient automatically if a file is missing, so nothing ever
looks broken while you're still gathering photos.

Drop in JPGs with these exact filenames:

| Filename                  | Used for                          | Suggested size |
|----------------------------|------------------------------------|-----------------|
| `hero.jpg`                 | Homepage hero background           | 1600×1000px     |
| `cat-vegetables.jpg`       | Vegetable Seeds category tile      | 800×600px       |
| `cat-flowers.jpg`          | Flower Seeds category tile         | 800×600px       |
| `cat-mix.jpg`              | Mix Seeds category tile            | 800×600px       |
| `cat-fertilizer.jpg`       | Fertilizer category tile           | 800×600px       |

Keep each under ~300KB (compress with squoosh.app or tinypng.com) so the
site stays fast on mobile data connections.
